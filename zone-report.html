📊 Power BI — Hub d'Intégration API
Gérez vos flux de données, générez des URL sur mesure et contrôlez les accès.
💡 Comment ça marche ?

Ce module vous permet de connecter vos données en direct à Power BI.
1. Créez une Clé API dans le panneau de droite.
2. Sélectionnez vos options dans le Constructeur d'URL (laissez "Tous les camions" pour exporter toute la flotte).
3. Copiez l'URL générée et collez-la dans Power BI via "Obtenir les données > Web".
