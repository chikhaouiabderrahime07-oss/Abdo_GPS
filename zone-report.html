Comment connecter Power BI (mode débutant)
01
Copier l'URL
Utilisez le constructeur ci-dessus, choisissez zone + type de données, puis copiez l'URL générée.
02
Importer dans Power BI
Obtenir des données → Web → coller l'URL → OK. Power BI charge automatiquement les données JSON.
03
Actualisation auto
Dans Power BI Service → Paramètres du jeu de données → Actualisation planifiée. Gratuit = jusqu'à 8×/jour.
💡 Astuce : Pour une mise à jour en quelques secondes (streaming réel), configurez POWERBI_PUSH_URL dans Render → les données sont envoyées dès qu'un camion entre/sort d'une zone, sans aucune attente.
